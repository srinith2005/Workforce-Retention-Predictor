# Employee Attrition Prediction

##  Overview

Employee attrition is a big problem for companies as losing experienced employees increases recruitment expenditure and also impacts productivity. This project employs Machine Learning for predicting the likelihood of an employee leaving the company based on employee-related information. The goal is to help HR teams to identify employees at risk and make better-informed retention decisions.

##  Features

- Data cleaning and preprocessing
- EDA (Exploratory Data Analysis)
- Attrition analysis by department, job role, salary, work-life balance
- One Hot Encoding and StandardScaler for Feature Engineering
- Training of Machine Learning models
- Comparison of different ML models
- Feature Importance analysis 
- Charts for data visualization
- Estimating employee attrition

##  Tech Stack

- **Language:** Python
- **IDE:** Jupyter Notebook
- **Libraries:**
  - Pandas
  - NumPy
  - Matplotlib
  - Seaborn
  - Scikit-learn

##  How It Works

1. Load the employee attrition data set.
2 Data Cleaning and Preprocessing
3. Drop unnecessary columns.
4. Categorical features encoding + numerical features scaling
5. Conduct exploratory data analysis.
6. Split dataset into train and test datasets.
7. Fit Logistic Regression, Random Forest and Gradient Boosting models.
8. For each model, calculate Precision, Recall, F1-Score, ROC-AUC Score and Confusion Matrix.
9. Select the most effective model.
10. Get feature importance and plot the results.
